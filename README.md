## 💾 Download for (Offline Use)
If you want a local copy on your computer (no internet required):

STEP 1 — Download the Files
Go to the GitHub repository - https://github.com/Harmni555/RealityTransurfingGuide
Click the green “Code” button
Click “Download ZIP”

STEP 2 — Extract the ZIP
Right-click the downloaded ZIP file
Select “Extract All…” (Windows)
Choose a location 

STEP 3 — Open the Tool
Open the extracted folder
Double-click index.html

That’s it — the tool will run in your browser locally.Download the ZIP → unzip → open `index.html` in your browser.
